# Interface: WorkHourSettings

禅道系统的工时设置。

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-dailyworkhours"></a> `dailyWorkHours` | `number` | 每日可用工时，单位为小时。 |
| <a id="property-effortunit"></a> `effortUnit` | `"day"` \| `"hour"` | 工时展示单位，`day` 表示日，`hour` 表示小时。 |
