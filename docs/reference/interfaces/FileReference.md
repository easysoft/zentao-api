# Interface: FileReference

HTML 图片或下载链接中的文件引用；路径和名称已解码 HTML 实体。

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-name"></a> `name?` | `string` | 从 alt、download、title、链接文本或来源路径提取的文件名。 |
| <a id="property-path"></a> `path` | `string` | 图片 src 或链接 href 中的原始路径。 |
